## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Express | Untrusted multipart file uploads and HTTP requests from any origin |
| Origin header → CORS middleware | Browser-supplied Origin header used for CORS gating |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Denial of Service | multer fileSize | mitigate | 20MB per-file hard limit via multer limits.fileSize; returns 413 before body is buffered past limit |
| T-01-02 | Tampering | HEIC fileFilter | mitigate | Dual check: file.mimetype in BLOCKED_MIME_TYPES AND /\.(heic|heif)$/i on originalname — handles browser MIME spoofing |
| T-01-03 | Elevation of Privilege | CORS origin | mitigate | Origin function validates against allowlist + regex; requests with disallowed origins receive CORS error |
| T-01-04 | Denial of Service | CORS middleware ordering | mitigate | corsMiddleware registered as absolute first app.use() — error responses carry CORS headers, preventing CORS-masked errors |
| T-01-SC | Tampering | npm install (sharp, multer, express, cors, archiver, p-limit) | accept | All packages verified in Package Legitimacy Audit in RESEARCH.md — all Approved, no [ASSUMED] or [SUS] packages |
</threat_model>
