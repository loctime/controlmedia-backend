POST /api/images/process (single image)
  Request:
    multipart/form-data
    field 'file': the image (JPG/PNG/WebP/AVIF/GIF) — REQUIRED
    field 'quality': 1-100 (optional; default 80)
    field 'format': 'jpeg' | 'png' | 'webp' | 'avif' (optional; default 'webp')
    field 'width': number in px (optional)
    field 'height': number in px (optional)
  Response 200:
    body: binary image (responseType: 'blob')
    Content-Type: image/<format>
    Content-Disposition: inline; filename="optimized.<format>"
    X-Original-Size: <bytes>
    X-Result-Size: <bytes>
    X-Reduction-Pct: <number 0-100>
    Access-Control-Expose-Headers: X-Original-Size, X-Result-Size, X-Reduction-Pct
  Response 400 (multer rejects HEIC at backend too):
    { "error": "INVALID_FILE_TYPE", "message": "..." }
  Response 400 (no file): { "error": "MISSING_FILE", ... }
  Response 413: { "error": "FILE_TOO_LARGE", ... }  (file > 20MB)
  Response 422: { "error": "PROCESSING_ERROR", ... }  (>25MP decompression bomb guard)

GET /health → 200 { "status": "ok" }  (used for warmup ping)

Backend CORS allows: https://controlmedia-*.vercel.app and localhost during dev.

Header note: axios normalizes response.headers keys to lowercase — always read
response.headers['x-original-size'], NOT 'X-Original-Size'.

Defaults to send on this plan (no UI to override yet):
  - quality: not sent → backend default 80
  - format: not sent → backend default 'webp' → preview file extension '.webp'

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User file → browser memory (DropZone) | Untrusted binary file content enters the browser before being shipped to Render |
| Browser → Render API (cross-origin POST) | FormData crosses CORS boundary to https://controlmedia-backend.onrender.com |
| Response blob → DOM (`<img src=...>`, `<a download>`) | Backend-supplied bytes are surfaced into the DOM via object URLs |
| Env var NEXT_PUBLIC_BACKEND_URL → bundle | Public env var is embedded at build time and visible to anyone who inspects the bundle |
